# 创建账号页校验提示布局修复设计

日期：2026-07-14  
状态：已确认

## 问题与根因

创建账号页给全部 `ElFormItem` 设置了 `!mb-0`，而 Element Plus 的 `.el-form-item__error` 默认绝对定位，不参与页面高度计算。错误提示出现后，后续输入框、协议勾选项和注册按钮不会下移，导致文字互相覆盖。

## 设计

修复范围仅限会员创建账号页：

1. 为表单项增加页面专用类，移除依赖 `!mb-0` 和 `space-y-*` 共同控制间距的方式。
2. 在该页面内将校验提示改为正常文档流，使提示出现时对应表单项自动增高。
3. 输入框错误提示紧随输入框显示；协议错误提示紧随对应勾选项显示。
4. 输入区、协议区、提交按钮和返回登录区域使用各自明确的间距，不使用负边距或固定高度补偿。
5. 保持现有字段、校验规则、配色和交互逻辑不变。

## 风险控制

- 样式使用 `scoped` 和页面专用类，不影响登录页、后台表单或其他 Element Plus 表单。
- 不通过固定预留错误高度解决，避免无错误时出现大块空白。
- 长提示允许自然换行，不设置可能截断文字的固定高度。

## 验收标准

- 用户名、密码、确认密码和手机号的错误提示不覆盖下一输入框或标签。
- 用户协议和隐私政策的错误提示不互相覆盖，也不覆盖注册按钮。
- 同时显示全部六项错误时，页面按内容自然增高且可以正常滚动。
- 在约 375px 手机宽度及桌面宽度下，输入框、提示、协议和按钮均无重叠或横向溢出。
- 清除错误后页面间距恢复自然，不遗留异常空白。
- 前端 lint、类型检查和生产构建通过。

## 影响范围与回滚

仅修改 `web/src/views/frontend/member/register.vue` 的表单布局类与局部样式。回滚时恢复该文件即可，不涉及接口、数据库或部署配置。
