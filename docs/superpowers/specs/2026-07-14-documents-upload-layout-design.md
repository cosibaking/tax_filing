# 经营资料库上传区布局修复设计

## 问题

经营资料库使用三列网格承载月份、通用上传组件和登记按钮。通用上传组件宽度为 100%，其内部上传按钮与提示没有明确的布局约束，导致上传按钮向左覆盖月份选择器。

## 范围

仅修改 `web/src/views/frontend/compliance/documents.vue` 的页面结构和局部样式，不修改 `MemberFileUpload` 通用组件、上传接口、资料登记逻辑或其他业务页面。

## 设计

- 桌面端使用三列布局：`180px minmax(0, 1fr) auto`。
- 月份选择器、上传组件和登记按钮处于同一行并顶部对齐。
- 为上传组件增加页面级容器，容器设置 `min-width: 0`，避免内容越过网格边界。
- 上传按钮与格式提示保留在上传列中；文件上传后，文件预览仍占该列。
- 登记按钮保持独立列，不随提示文本移动。
- 宽度不超过 760px 时切换为单列布局，各控件宽度为 100%。

## 验收标准

1. 1440px、1200px 和常见会员中心内容宽度下，三项保持同一行且互不覆盖。
2. 格式提示位于上传按钮下方，不进入月份选择器区域。
3. 选择文件后预览区域不撑破上传列。
4. 760px 以下为单列布局，无水平滚动。
5. 前端 ESLint、TypeScript 检查和生产构建通过。

## 风险与回滚

修改为页面局部 CSS，风险仅限经营资料库上传区。回滚时恢复该 Vue 文件即可，不涉及接口和数据库。
