## 冒烟路径

```
/ → /diagnosis → /diagnosis/result
→ /user/register → /user/compliance/plan → /user/compliance/opc
→ (admin) /admin/compliance/opc-tasks
→ /user/compliance/income → expense → ledger → tax → statement
```

## 已知限制（MVP Out of Scope）

- 无真实电子税务局 API
- 无腾讯电子签（姓名确认 + PDF 存档）
- 无在线支付
- CSV 导入（无 OCR）
