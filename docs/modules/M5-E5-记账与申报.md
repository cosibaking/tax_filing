## 三、P1 详细设计

### 3.1 标准账套科目（F-44 Seed）

| 代码 | 名称 | 类型 |
|------|------|------|
| 1001 | 银行存款 | 资产 |
| 6001 | 主营业务收入 | 收入 |
| 6401 | 管理费/推广费 | 费用 |

### 3.2 自动分录规则（F-45）

| 事件 | 借方 | 贷方 |
|------|------|------|
| 确认收入 | 银行存款 | 主营业务收入 |
| 确认费用 | 管理费/推广费 | 银行存款 |

### 3.3 税种计算

**增值税（F-51）：**
```
不含税 = 含税 ÷ 1.01
若月不含税 < 100000 → 0
否则 不含税 × 1%
```

**附加税（F-55）：** `vat × 0.06`（无 VAT 则为 0）

**企税季度预缴（F-52）：** `max(0, 季度累计利润) × 5%`（利润≤300万）

**年度汇算（F-53）：** 次年5/31 生成 `cit_annual` 任务

### 3.4 自查清单九项（F-69，PRD 附录 B）

1. 收入流水是否与平台数据一致？
2. 是否有该申报未申报的发票？
3. 成本费用发票是否已入账？
4. OPC 是否有员工要报工资个税？
5. 本季度增值税申报了吗？
6. 企业所得税预缴了吗？
7. 有员工的话，社保申报了吗？
8. 主播是否还有其他平台收入要合并计算？
9. 上一期申报是否有错误要更正？

### 3.5 数据模型

```prisma
model LedgerAccount {
  id   BigInt @id @default(autoincrement())
  code String @unique
  name String
  type String
  @@map("ledger_accounts")
}

model LedgerVoucher {
  id            BigInt   @id @default(autoincrement())
  opcId         BigInt   @map("opc_id")
  period        String   // 2026-06
  debitAccount  String   @map("debit_account")
  creditAccount String   @map("credit_account")
  amount        Decimal  @db.Decimal(14, 2)
  refType       String   @map("ref_type")
  refId         BigInt   @map("ref_id")
  createdAt     DateTime @default(now()) @map("created_at")
  @@index([opcId, period])
  @@map("ledger_vouchers")
}

model ProfitSummary {
  id                BigInt  @id @default(autoincrement())
  opcId             BigInt  @map("opc_id")
  year              Int
  month             Int
  revenue           Decimal @db.Decimal(14, 2)
  cost              Decimal @db.Decimal(14, 2)
  profit            Decimal @db.Decimal(14, 2)
  cumulativeProfit  Decimal @map("cumulative_profit") @db.Decimal(14, 2)
  @@unique([opcId, year, month])
  @@map("profit_summaries")
}

model TaxFilingTask {
  id               BigInt    @id @default(autoincrement())
  opcId            BigInt    @map("opc_id")
  taxType          String    @map("tax_type") // vat, cit_quarterly, cit_annual, surcharge
  period           String
  dueDate          DateTime  @map("due_date")
  status           String    // pending, filed, overdue
  calculatedAmount Decimal   @map("calculated_amount") @db.Decimal(14, 2)
  filedAmount      Decimal?  @map("filed_amount") @db.Decimal(14, 2)
  receiptFileId    BigInt?   @map("receipt_file_id")
  checklist        Json?
  deleted          Boolean   @default(false)
  createdAt        DateTime  @default(now()) @map("created_at")
  @@index([opcId, period])
  @@map("tax_filing_tasks")
}
```
