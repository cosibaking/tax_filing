## 三、P1 详细设计

### 3.1 站点地图

```
Portal: /, /diagnosis, /diagnosis/result, /pricing, /legal/*
Member: /user/overview, /user/compliance/*, /user/profile, /user/notification, /user/login, /user/register
Admin: /admin/compliance/*
```

### 3.2 公开区顶栏

```
[Logo] 首页 | 免费诊断 | 服务价格 | [登录] [注册]
```

已登录显示「会员中心」→ `/user/overview`

### 3.3 会员侧栏动态规则（§5.2）

| 菜单 | 路径 | 显示条件 |
|------|------|---------|
| 概览 | `/user/overview` | 始终 |
| 诊断历史 | `/user/compliance/diagnosis` | 始终 |
| 方案与签约 | `/user/compliance/plan` | 无 active 订单 |
| OPC 进度 | `/user/compliance/opc` | 有订单且 OPC 未 active |
| 收入/费用/利润/申报/对账单 | 各路径 | OPC status=active |

### 3.4 引导规则（§5.3）

| 状态 | 引导 |
|------|------|
| 未签约 | 黄条 → `/user/compliance/plan` |
| OPC 设立中 | 台账菜单置灰 |
| 待上传材料 | 概览红色待办 |

### 3.5 组件结构

```
components/portal/PortalHeader.tsx
components/portal/PortalFooter.tsx
components/member/MemberLayout.tsx
components/member/MemberSidebar.tsx
components/member/ComplianceGuard.tsx  # OPC active 检查
lib/portal/member-nav.ts               # 动态菜单配置
```

### 3.6 响应式

- 移动优先：表格→卡片
- 侧栏→Drawer
- CTA 最小 44×44px
