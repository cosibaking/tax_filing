## 三、P1 详细设计

### 3.1 对账单内容（F-61，实操手册 5.2）

- 本月收入 / 成本 / 利润
- 本月预缴税额
- 累计年度利润
- 申报状态：已申报完成

### 3.2 合规规则引擎（F-68）

| 规则 | 触发 | 动作 |
|------|------|------|
| 禁止借款/赠与收入类型 | 收入录入 | 类型不可选 + 备注关键词拦截 |
| 低报收入 | 申报 filedAmount < 台账汇总 | 阻断 |
| 虚增成本 | M4 已实现 | 复用 |

### 3.3 审计留痕（F-74）

记录 action：`income.update`, `expense.delete`, `consent.plan_confirm`, `filing.mark_filed` 等

### 3.4 数据模型

```prisma
model MonthlyStatement {
  id         BigInt    @id @default(autoincrement())
  opcId      BigInt    @map("opc_id")
  year       Int
  month      Int
  summary    Json
  pdfFileId  BigInt?   @map("pdf_file_id")
  sentAt     DateTime? @map("sent_at")
  deleted    Boolean   @default(false)
  createdAt  DateTime  @default(now()) @map("created_at")
  @@unique([opcId, year, month])
  @@map("monthly_statements")
}
```
