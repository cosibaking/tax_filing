## 三、P1 详细设计

### 3.1 税负计算公式（PRD §6.2–6.4）

**劳务报酬（简化年估）：** 超额累进，年入100万约27%

**个体户（查账征收）：**
```
应纳税所得额 = 年收入 - 可扣除成本
按经营所得5级累进：5%/10%/20%/30%/35%
```

**OPC（小微有限公司）：**
```
不含税收入 = 含税收入 ÷ 1.01
增值税：月销<10万免税，否则 不含税×1%
附加税：增值税 × 6%（减半后）
企税：年利润≤300万，实际5%；季度预缴
综合税负 ≈ 企税 + 分红20%（若全额分红）
简化展示：年利润×5% + 可选分红模拟
```

**不报税：** 固定高危警告，税额显示为「潜在补税+罚款风险」

### 3.2 推荐规则（F-03）

| 年收入区间 | 推荐 |
|-----------|------|
| <30万 | individual 或 transitional |
| 30–100万 | individual / opc 视成本 |
| 100万+ | opc |
| 已被税局联系 | opc + 顾问跟进提示 |

### 3.3 数据模型

```prisma
model ComplianceDiagnosis {
  id                  BigInt   @id @default(autoincrement())
  memberId            BigInt?  @map("member_id")
  platforms           Json
  monthlyIncomeRange  String   @map("monthly_income_range")
  annualCostEstimate  Decimal  @map("annual_cost_estimate") @db.Decimal(14, 2)
  existingEntity      String   @map("existing_entity")
  hasFiledTax         Boolean  @map("has_filed_tax")
  taxBureauContact    Boolean  @map("tax_bureau_contact")
  recommendedPlan     String   @map("recommended_plan")
  taxComparison       Json     @map("tax_comparison")
  deleted             Boolean  @default(false)
  createdAt           DateTime @default(now()) @map("created_at")
  @@map("compliance_diagnoses")
}
```
