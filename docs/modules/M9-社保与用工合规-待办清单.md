## 六、已知限制与技术债

1. **清单 key 不一致**：会员端 `member.ts` 中历史常量使用 `salary_tax`，后端为 `payroll_tax`；API 返回以后端为准，静态常量仅作兜底。
2. **`has_employee` 不可改回 `no_employee`**：Phase 3 员工表上线后需增加「无在职员工」校验再允许回退。
3. **咨询权限**：仅校验套餐 `tier` 为 `advanced`/`premium`，未单独配置功能开关。
4. **指引内容**：当前为 SQL 种子静态 Markdown，无后台 CMS 编辑入口。
