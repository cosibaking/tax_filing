## 三、P1 详细设计

### 3.1 收入类型（F-27，禁止借款/赠与 F-68）

`tip`, `commission`, `ad`, `slot_fee`, `offline`, `other`

### 3.2 费用类型库（F-37 Seed）

| code | 名称 | 所需凭证 |
|------|------|---------|
| equipment | 设备 | 发票 |
| network | 网费 | 发票 |
| venue | 场地 | 合同+发票 |
| promotion | 投流 | 平台发票 |
| outsource | 外包 | 合同+发票 |
| travel | 差旅 | 车票/住宿票 |
| other | 其他 | 说明+凭证 |

### 3.3 虚增拦截（F-38）

- 成本/收入比 > 80%（可配置 `COMPLIANCE_COST_RATIO_THRESHOLD`）→ 警告+二次确认
- 关键词黑名单：`咨询费`, `服务费`, `借款`, `赠与` → 禁止或强制审核

### 3.4 数据模型

```prisma
model IncomeEntry {
  id           BigInt   @id @default(autoincrement())
  opcId        BigInt   @map("opc_id")
  platform     String
  category     String
  grossAmount  Decimal  @map("gross_amount") @db.Decimal(14, 2)
  platformFee  Decimal  @map("platform_fee") @db.Decimal(14, 2)
  netAmount    Decimal  @map("net_amount") @db.Decimal(14, 2)
  occurredAt   DateTime @map("occurred_at")
  source       String   @default("manual")
  deleted      Boolean  @default(false)
  createdAt    DateTime @default(now()) @map("created_at")
  @@index([opcId, occurredAt])
  @@map("income_entries")
}

model ExpenseEntry {
  id           BigInt   @id @default(autoincrement())
  opcId        BigInt   @map("opc_id")
  category     String
  amount       Decimal  @db.Decimal(14, 2)
  invoiceType  String   @map("invoice_type")
  attachmentId BigInt?  @map("attachment_id")
  description  String?  @db.Text
  warningFlag  Boolean  @default(false) @map("warning_flag")
  occurredAt   DateTime @map("occurred_at")
  deleted      Boolean  @default(false)
  createdAt    DateTime @default(now()) @map("created_at")
  @@index([opcId, occurredAt])
  @@map("expense_entries")
}

model BankTransaction {
  id          BigInt   @id @default(autoincrement())
  opcId       BigInt   @map("opc_id")
  occurredAt  DateTime @map("occurred_at")
  amount      Decimal  @db.Decimal(14, 2)
  description String?  @db.Text
  matched     Boolean  @default(false)
  incomeId    BigInt?  @map("income_id")
  deleted     Boolean  @default(false)
  createdAt   DateTime @default(now()) @map("created_at")
  @@map("bank_transactions")
}

model ExpenseCategory {
  id          BigInt  @id @default(autoincrement())
  code        String  @unique
  name        String
  voucherHint String  @map("voucher_hint") @db.Text
  active      Boolean @default(true)
  @@map("expense_categories")
}
```
