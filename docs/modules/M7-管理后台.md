## 三、P1/MVP 详细设计

### 3.1 页面

| 路径 | 原型 | 功能 |
|------|------|------|
| `/admin/login` | — | 管理员登录 |
| `/admin/compliance/customers` | — | 客户简版列表 F-79 |
| `/admin/compliance/opc-tasks` | P-15 | F-17~19 |
| `/admin/compliance/filing` | P-16 | F-51~53, F-69 |
| `/admin/compliance/statements` | P-17 | F-61 |

### 3.2 OPC 任务操作

- 筛选：status、搜索手机号/公司名
- 行操作：更新节点（materials→business→tax→bank→active）、备注、上传执照

### 3.3 申报工作台

- 标记已申报前强制完成 9 项自查（F-69）
- 上传回执 PDF（F-60 简版）
- 批量列表按税种/月份筛选

### 3.4 API

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/admin/auth/login` | 管理员登录 |
| GET | `/api/admin/compliance/customers` | 客户列表 |
| GET/PATCH | `/api/admin/compliance/opc-tasks` | OPC 队列 |
| GET/PATCH | `/api/admin/compliance/filing` | 申报任务 |
| POST | `/api/admin/compliance/statements/send` | 生成/发送对账单 |
| GET | `/api/admin/compliance/audit/export` | 留痕导出 CSV |

### 3.5 鉴权

- `AdminUser.role`: `advisor` | `admin`
- MVP：所有 admin 用户可访问全部 compliance 菜单
